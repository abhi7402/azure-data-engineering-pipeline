🚀 Excited to announce my new Azure Data Engineering Project! I'm building an end-to-end Real-Time Sales Analytics Pipeline on Microsoft Azure — and I'll be documenting every step of the journey right here on LinkedIn. 🏗️ What I'm building: A complete data pipeline using the Medallion Architecture (Bronze → Silver → Gold) that ingests raw sales data, transforms it using PySpark, and delivers business insights via a Power BI dashboard. 🛠️ Tech Stack: → Azure Data Factory — for data ingestion & orchestration → ADLS Gen2 — as the Data Lake (Bronze/Silver/Gold layers) → Azure Databricks — for PySpark transformations → Azure Synapse Analytics — as the data warehouse → Power BI — for interactive dashboards 💡 Why this project? This architecture is used by companies like Microsoft, Accenture, and Deloitte in production. Building this gives hands-on experience with the exact tools that data engineering teams use every day. 📅 Timeline: 4 weeks | ☁️ Platform: Microsoft Azure I'll be posting weekly updates with screenshots, code snippets, and lessons learned. Follow along if you're interested in Data Engineering, Cloud, or Azure! 🙌 GitHub link coming soon 👇
